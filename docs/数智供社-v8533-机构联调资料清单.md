# 数智供社 v8533 机构联调资料清单

本清单用于把真实机构资料交给后端适配和验收人员。它只登记非秘密的元数据和受控证据编号，不保存任何密码、私钥、AppSecret、支付密钥、回调密钥或完整敏感报文。

## 提交边界

可以登记：机构名称、产品名称、沙箱/生产环境标识、API 根地址、回调路径、接口文档版本、来源 IP 要求、联调负责人、合同编号后四位、验收报告编号。

不得登记：任何访问令牌、私钥、证书私密部分、微信 AppSecret、支付 API 密钥、数据库密码、管理员令牌或可直接重放的完整报文。密钥应放在服务器密钥管理系统，环境文件只由运维注入。

## A. 平台基础资源

| 项目 | 填写内容 | 验收证据 |
| --- | --- | --- |
| 正式前台域名 | 例如 `app.正式域名.cn` | DNS/TLS 报告编号 |
| 正式 API 域名 | 例如 `api.正式域名.cn` | `/health/live`、`/health/ready` 回验编号 |
| CORS 来源 | 必须是完整 HTTPS 根来源 | 预检回验编号 |
| API 部署区域 | 云厂商/地域/安全组 | 网络变更单编号 |
| 数据库方案 | 灰度 SQLite 或正式 MySQL/PostgreSQL | 备份恢复报告编号 |
| 备份策略 | 周期、保留天数、恢复窗口 | SHA-256 与隔离恢复编号 |

## B. 微信认证

| 项目 | 填写内容 | 验收证据 |
| --- | --- | --- |
| 主体名称 | 小程序/公众号主体 | 主体核验编号 |
| AppID | 只登记 AppID，不登记 AppSecret | 微信平台配置截图或报告编号 |

| 测试用户 | 受控用户编号，不写个人隐私 | 绑定、轮换、退出失效编号 |

## H. 适配器实现交付物

每个机构完成后，必须同时提交：

1. 机构适配器字段映射和版本号；
2. 出站 `Command` 与入站 `Callback` 的样例摘要（脱敏）；
3. 独立的适配器地址和签名密钥引用；
4. 超时、重试、幂等、撤销/退款/红冲或异常补偿规则；
5. 沙箱回执、生产切换审批和验收证据编号。

资料齐全后，只在服务器受限环境中填写对应配置，并逐项执行：

```bash
SHUZHI_ENV_FILE=/etc/shuzhi-v8530.env npm run check:shuzhi-production-env
SHUZHI_ENV_FILE=/etc/shuzhi-v8530.env npm run check:shuzhi-activation
```

没有对应机构的合同、字段文档、回执和验收证据时，保持对应 `SHUZHI_*_READY=false`，不得用本地模拟回调替代真实开通。
