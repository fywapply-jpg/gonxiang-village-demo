## 放行顺序

1. 运维填写受限环境文件并完成域名、TLS、CORS、数据库和备份验收。
2. 微信、CA、支付、物流、发票、监管六类机构分别完成联调；每类使用独立密钥，不共用回调密钥。
3. 执行 `npm run check:shuzhi-production`，确认 0 失败；再执行 `npm run check:shuzhi-startup` 和 `npm run verify:production-deployment`。
4. 只开放一条支付线路、一个物流承运商和已核验的采购商/供货商，设置金额、订单量和风险阈值，完成首批灰度。
5. 灰度通过后再推广；任何主体、资金、验收或回调证据异常，先暂停写入和回调消费，再按审计日志与备份回滚。
