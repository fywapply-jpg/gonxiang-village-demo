## 本地三层结构

```text
微信小程序 / H5 手机前台  →  REST API（8787）  →  SQLite 数据库
管理后台（5180）           →  REST API（8787）  →  SQLite 数据库
```

根目录一键启动：

```bash
npm run dev:local
```

- 手机 H5：`http://localhost:5173`
- 管理后台：`http://localhost:5180`
- 后端健康检查：`http://localhost:8787/health`
- 数据库：`local-backend/data/shuzhi.db`

## 微信开发者工具联调

微信开发者工具中可关闭“域名校验”，然后在本机启动后端：

```bash
npm run dev:local-api
```

真机预览时，微信端不能使用 `localhost`。请把 `VITE_API_BASE` 设置为电脑局域网 IP 后重新编译：

```bash
npm run build:shuzhi-mp
```

手机和电脑必须在同一个 Wi-Fi；电脑防火墙需允许 8787 端口。

## 正式发布要求

真机正式版不能使用局域网 HTTP 地址。后端需要部署到 HTTPS 域名，并在微信公众平台“开发 → 开发管理 → 开发设置 → 服务器域名”配置 `request 合法域名`，然后用该域名编译：

```bash
VITE_API_BASE=https://api.example.com npm run build:mp-weixin
```

支付、登录、文件上传等能力还需分别配置对应的业务域名和微信审核资质。本地 SQLite 仅用于开发、演示和联调；当前 v8533 前台使用 `local-backend/server.mjs` 的 legacy BFF 契约，不能直接切换到 `cloud-server/`。生产迁移到 MySQL 前必须先完成独立兼容适配层、身份字段转换、幂等语义和机构联调，并通过 `npm run check:shuzhi-frontend-backend`。

## 当前前后台边界

- 小程序/H5 负责交易大厅、数字种养、溯源、金融、物流等业务操作与演示。
- 管理后台单独运行在 5180，查看交易、商家资质、支付状态和审计日志。
- 前台不直接访问数据库，只调用 `/api/v1`；批量交易工作台的状态推进会同步写入本地后端履约事件和审计日志。
