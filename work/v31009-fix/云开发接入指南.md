## 二、你要操作的 5 步

### 第 1 步　打开项目
1. 终端进入项目，先构建一次：
   ```
   cd /Users/fengwen/gonxiang-miniapp-v2
   npm run build:weapp
   ```
2. 微信开发者工具 → **导入项目** → 目录选 `gonxiang-miniapp-v2` → AppID 用 `wxcb4fe0515e5fa25e`（或换成你自己的）

### 第 2 步　开通云开发、创建环境
1. 工具顶部点 **「云开发」** 按钮 → 开通（选 **免费基础版** 即可）
2. 创建一个环境，名字随意（如 `gonxiang-prod`）
3. 复制 **环境ID**（形如 `gonxiang-prod-9xxxxx`）

### 第 3 步　填入环境ID
打开 `src/utils/cloud.ts`，把第一行常量改掉：
```ts
export const CLOUD_ENV = 'gonxiang-prod-9xxxxx';  // ← 粘贴你的环境ID
```
然后重新 `npm run build:weapp`。填了ID = 自动切到云端真实数据。

### 第 4 步　部署 3 个云函数
工具左侧文件树展开 `cloudfunctions/`，分别右键：
- `login` → 「上传并部署：云端安装依赖」
- `proposals` → 同上
- `contribution` → 同上

每个等到提示"部署成功"。（首次会自动 npm install wx-server-sdk）

### 第 5 步　建 3 个数据库集合
云开发控制台 → **数据库** → 新建集合，建这三个（名字必须一致）：
- `users`
- `proposals`
- `contributions`

每个集合 → **权限设置** → 选 **「仅管理端可读写」**
（数据只通过云函数读写，最安全；云函数自带管理员权限）

## 三、怎么确认通了

重新编译，在模拟器里：
1. **账户**：退出登录 → 微信一键登录 → 能进首页；云开发控制台 `users` 集合里多出一条记录
2. **发帖多人共享**：进「村民议事」→ 右下角「发起提案」→ 输入一句话 → 提案出现在列表；`proposals` 集合有记录。**换一个微信号登录，也能看到同一条提案** ← 这就是真后端
3. **投票 + 贡献值**：给提案投票 → 提示 +20 贡献值 → 进「贡献体系」页，贡献值和排名来自云端 `contributions` 集合

## 五、关于"降级开关"

`src/utils/cloud.ts` 的 `CLOUD_ENV`：
- **留空** → 全本地演示数据（当前状态），适合没网络/还没开通时给客户演示
- **填了环境ID** → 连云端真实数据，多人共享、跨设备

随时可切换，互不影响。
