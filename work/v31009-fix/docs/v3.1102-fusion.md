# 供享村社 v3.1102 融合升级说明

## 版本定位

v3.1102 在 v3.1009 的党建、城乡流通、村务治理和便民服务基础上，融合“数字乡村操作系统、万村互联、智慧农业和数字文化”能力。原有界面风格、商品交易和治理入口继续保留。

## 交互原则

- 已有真实页面直接复用，避免同一业务出现两套入口和两套状态。
- 新增中台、农业、全国网络和数字文化目前为试点能力展示。
- 需要写入数据的按钮明确提示“需接入后端工作流”，不在前端伪造提交成功。
- 数字族谱与村民档案按户授权、分级可见，敏感个人信息不得默认公开。
