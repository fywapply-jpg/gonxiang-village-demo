# v3.1102 信息架构收敛

## 目标

从“几十个功能图标平铺”改为“先选办事场景，再选具体业务”。功能不删除，入口统一、重复路由去重、权限规则保持不变。

## 五个场景中心

| 场景中心 | 整合内容 | 主要用户 |
|---|---|---|
| 办事与生活 | 政务、社保、医疗、养老、就业、维修、物业、代办 | 村民/居民 |
| 治理与共建 | 村务公开、议事、网格、调解、党建、六级治理 | 群众与治理人员 |
| 产业与交易 | 农业生产、产销对接、农资农机、乡村商品、全国协作 | 村民、经营者、消费者 |
| 公益与文化 | 公益项目、志愿服务、邻里互助、非遗、文明、文旅 | 全体用户 |
| 组织管理 | 审批、名册、权限、运营、审计 | 有管理权限的用户 |

## 展示规则

- 首页最多显示 4 个群众场景中心；管理用户多显示 1 个组织管理。
- 首页不再展示单个功能图标，改为序号、场景名和一句用途。
- 中心页用“分组+文字行”，不使用大图标宫格。
- 同一场景中心内，最终路由相同的入口只保留一次。
- 村/社区、党员、管理员和功能开关继续沿用原有过滤规则。
