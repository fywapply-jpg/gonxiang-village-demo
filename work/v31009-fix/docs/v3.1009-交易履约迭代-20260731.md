# 供享村社 v3.1009 · 交易履约迭代存档

更新时间：2026-07-31

## 本轮落地

1. 首页货架、商品详情、购物车改用同一份货品资料。
2. 首页首批货品使用真实图片，展示完整产地、供货主体、规格、价格、库存和销量。
3. 商品详情的规格切换同步改变价格和库存。
4. 修复购物车“一键支付”被底部导航遮挡、误触其他入口的问题。
5. 手机入口统一使用相对资源路径，保留 `index.html`、`app.html`、`m.html`、`demo.html` 四个入口。
6. 店主端只展示本店订单；平台运营可查看和兜底处理全平台订单。
7. 店主发货时选择“平台同城配送”或“顺丰速运”，运单号、电话和物流动态写入真实订单。
8. 买家退款改为“提交申请 → 商家审核 → 退款完成”，不再点击后直接退款。
9. 商家同意退款后，自动冲正待确认消费贡献值，并退回该单已使用的抵扣贡献值。
10. 买家确认收货后，订单消费贡献值才正式到账。
11. 买家评价写回订单；对应店主可查看真实评分、评价标签和商品信息。

## 已实测通过的跨角色流程

- 村民下单 → 店主看到本店订单 → 店主选择承运方发货 → 村民查看真实物流 → 村民确认收货 → 消费贡献值到账 → 村民评价 → 店主看到评价。
- 村民申请退款 → 订单进入退款中 → 平台运营 / 对应店主审核 → 退款完成 → 支付权益和贡献值自动冲正。
