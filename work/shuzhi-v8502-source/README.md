## 一套代码，两个产物

采用细则推荐的 **uni-app + Vue3 + TypeScript + Pinia + Vite** 技术栈，同一份源码可同时编译为：

| 目标 | 命令 | 用途 |
|---|---|---|
| **H5 公网演示** | `npm run dev:h5` / `npm run build:h5` | 手机/微信打开即像小程序，给领导、合作方快速演示 |
| **微信小程序** | `npm run dev:mp-weixin` / `npm run build:mp-weixin` | 用微信开发者工具打开 `dist/build/mp-weixin`；正式提审前必须完成真实 HTTPS API 和机构联调 |

> 微信小程序需在 `src/manifest.json` 的 `mp-weixin.appid` 填入企业主体 AppID，并用微信开发者工具打开编译产物目录。

## 已实现（对应细则「三、功能模块详细目录」9 大模块全走查）

0. **登录/启动页**（紫色渐变品牌页）— 数智供销 品牌区、微信一键登录、手机号授权、游客扫码入口、隐私协议、登录时选择体验身份（对应细则「微信一键登录免注册」）
1. **角色化首页** — 5 类角色自动适配、全局搜索、价格指数看板、应急保供、扫码入口
2. **农产品 B2B 交易** — 供货大厅 / 采购大厅、供需发布、订单全生命周期、询盘 IM
3. **农资集采** — 分类商城、拼团集采、订单农业合约
4. **全链路可信溯源** — 扫码直达、种植→加工→流通→销售四段、长安链存证一键验真、海报/举报
5. **供应链金融（合规入口式）** — 产品矩阵、额度测算、融资申请、信用资产中心、农业保险、全民分红
6. **仓储物流** — 运单实时追踪、冷链温湿度、电子仓单质押
7. **基层服务站** — 入驻代办、业务登记、设备运维、站点数据看板
8. **商户中心** — DID 链上身份、钱包、大字模式、隐私设置
9. **消息中心** — 订单/询盘/金融/物流/公告分类 + 微信订阅消息

**演示技巧**：右下角金色「切角色」悬浮按钮可切换供应商 / 采购商 / 农资采购方 / 服务站专员 / 访客，首页与权限随之变化。

## 合规红线（已在设计中体现）

- 金融模块仅信息展示与申请入口，资金放款/还款跳转持牌机构，平台不触碰资金、不放贷；
- 双链分离叙事（长安链存证 + 交易流转链），不涉及虚拟货币；
- 大字模式、微信一键登录等县域低门槛适配。

## 目录结构

```
src/
  pages/         # 31 个页面，按 9 大模块分目录
  components/    # RoleSwitcher 等公共组件
  store/         # Pinia：user(角色) / app(大字模式/通知)
  mock/          # 纯前端演示数据（生产环境由主平台 BFF 层替换）
  uni.scss       # 设计变量（供销绿 / 链上金 / 溯源蓝）
```
